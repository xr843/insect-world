# 碧伟蜓局部内容核校

核对日期：2026-10-17，物种 `dragonfly` / 站内学名 *Anax parthenope*。核对范围：体形与分布、东亚类群的羽化与产卵习性、捕食成功率、拦截机制和复眼相关叙述。不代表整物种所有字段已核验完成，未做昆虫学专家复审。

## 分类口径问题

碧伟蜓对应日本称ギンヤンマ的东亚类群 *Anax parthenope julius*。日本百科写明，印度以西至欧洲分布的是另一亚种（乾燥地型的原亚种）。GBIF 骨干把 *Anax julius* Brauer, 1865 列为独立接受种（Oriental Lesser Emperor），香港湿地公园也把碧偉蜓标为 *Anax julius*。站内英文名 Lesser Emperor 和原分布「欧亚大陆及非洲北部」对应的是指名亚种。

本轮按要求不改 latin 与英文名，留给维护者做结构决定。正文中的体长、分布、羽化期、产卵等改用日本百科对东亚类群的记载，分布字段注明印度以西为指名亚种。英文版因此暂时出现「英文名指向指名亚种、正文描述东亚类群」的不一致，需在结构决定后统一。

## 改动与边界

- **总述**：删去「能悬停、瞬间转向」「稚虫水中数月至一年」「活跃的伏击型捕食者」。改为日本百科支持的内容：体长约70毫米、体色、幼虫生于低地池沼、羽化盛夏最多、未成熟成虫在空地觅食、成熟雄虫到池沼寻找雌虫。
- **体长**：原「65–75毫米、翼展90–100毫米」无来源。改为「约70–80毫米（百科记载不一）、后翅长约50–55毫米」，保留「数字–数字毫米」形式供体长对比条解析。
- **生活史与生活周期**：删去幼虫期「数月至一年」和成虫期「1–2个月」，不采用 Mypedia 的约2年。改为幼虫在低地池沼发育、日本记录约5–9月羽化。
- **栖息环境**：删去「缓流水域」「周边草丛」，改为低地池沼及周边、水田，幼虫栖于水草多的池沼。
- **食性**：来源均未列出本种幼虫或成虫的具体猎物，删去「孑孓、小鱼虾、蚊蝇」，改为未成熟成虫在空地上空约1–2米觅食飞行。
- **飞行**：删去时速30公里以上和两对翅独立扇动实现悬停急转。改为香港物种卡的「飞行迅速」和日本百科的「成群渡海迁移」。前翅、后翅热点和第二节课程一并删去不同步扇动、主要升力、长时间悬停、倒退飞行，改为翅色、后翅长度、渡海迁移和北海道罕见。
- **视觉**：「近3万个小眼」改为蜻蜓目「最多约三万个」，并标明是类群上限；删去「视野接近360度」「几乎没有盲区」「每个小眼独立成像」。复眼热点和第一节课程补入综述支持的偏振光与寻找水域。中文写汉字「三万」、英文写 thirty thousand，以保持中英数字串一致。
- **腹部、胸部热点**：删去抱握器钳住雌虫头部、胸部倾斜使着生点错开（来源均未涉及）。改为日本百科的体色记载：雄虫第2腹节背面蓝色、第3腹节侧面银色；胸部绿色无斑，与同属 *A. nigrofasciatus* 胸侧两条黑纹相区分。近缘种只写学名，不引入来源外的中文名。
- **足**：来源均未描述足篮捕食，删去「密生刚毛、收拢成篮」。热点和第三节课程（anchor 仍为 leg）改为说明足的作用尚待核实，并引用 Combes 对别属蜻蜓的观察：多从下方接近猎物、捕获不到半秒。课程标题改为「从下方接近」。该节内容与锚点的关联偏弱，是保留 anchor 的折中做法。
- **冷知识、动态卡、第一道测验**：删去约95%成功率、高于狮子、神经元预判轨迹是高成功率的核心、成功率九成以上。
  - 冷知识改为 Combes 别属实验的83%至95%中位数，标明非碧伟蜓、户外人工环境、猎物为果蝇，并写明随机转弯导致的失败多于闪避。
  - 动态卡改为 Mischiati 摘要中的头部预测性转动与模型驱动转向，加上 Wiederman 的小目标神经元前方增益，均标明是别属或其他蜻蜓。
  - 第一道测验原答案依赖被删说法，改问该实验中造成失败最多的因素，answer 下标仍为1；干扰项「飞行速度超过蜻蜓」与论文中蜻蜓运动表现占优的结果相反。
- **第二道测验**：原题依赖「不完全变态、无蛹、多次蜕皮」，本轮来源未涉及，改问来源支持的幼虫生境与产卵位置，answer 下标仍为1。metamorphosis 结构字段未改。
- **生态**：删去「重要捕食者」「大量取食蚊虫幼体」「鱼鸟的重要食物」。改为日本幼虫因水体污染减少，以及蜻蜓目觅食伴随被捕食风险的研究背景。
- **栖息卡**：删去雄虫常年巡逻守卫领地、稚虫在淤泥中伏击。改为未成熟成虫在空地觅食、成熟雄虫到池沼寻找雌虫、雌虫单独或连结产卵于漂浮植物。
- **分布**：删去「欧亚大陆及非洲北部温带、亚热带」，改为日本（北海道少见）、朝鲜半岛、中国大陆及台湾；印度以西至欧洲为指名亚种。北非未见于本轮来源。
- **仍未核校的字段**：
  - status「常见」：仅有日本百科「普通種」作依据，同一来源也记北海道罕见、近年减少。
  - relatives：三个中文名均为蜻科种类，与来源列出的同属近缘种不符；来源没有这些近缘种的中文名，本轮未替换。
  - epithet、metamorphosis 及生活周期中「无蛹」的含义、中英文名。
- 来源区每条只列支持范围与获取方式，不添加整物种「已验证」标记。
- **测试影响**：上一批测试以蜻蜓作为无来源案例；本轮接入来源后，需改用另一个尚未接入的物种。本批（2026-10-17）五种完成后，共九个物种接入部分断言来源，另54个尚未接入。
