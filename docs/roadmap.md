# 物种路线图

**阶段目标 50 种**（长期 60）。每一种的入选标准只有一条：**有一个别的物种没有的招牌结构**，
且这个结构能在程序化建模里做出来、能在 24×24 的剪影里认出来。

数量不是目的。凑不出招牌特征的物种宁可不做 —— 图鉴的价值在于每一页都值得看，
而不在于页数。甲虫尤其要注意：鞘翅目物种数最多，但大量差异在刻点、绒毛、
斑纹这类**细部**上，当前精度表达不出来，做出来就是「又一只褐色的甲虫」。

## 每轮的作业顺序

1. 从上表取 8 种，派 3 个建模 agent + 1 数据 + 1 讲解 + 1 剪影
2. 跑全量测试与 `tsc`
3. **在 `/preview.html` 里逐个放大目视验收** —— 这一步不能省，也不能抽查。
   测试全绿不等于长得像：萤火虫曾被做成两只虫黏一起、螳螂趴平成绿枝、
   帝王蝶糊成一片褐色，当时测试全是绿的。
   第 5 轮更极端 —— 10 种里 7 种测试全绿却要返工，两类原因各占一半：

   **颜色压过了头。** 渲染走 ACES 色调映射，会提亮去饱和，于是有了「颜色要压深
   一档」这条经验。但它被当成了「越深越保险」：大王花金龟前胸的黑白纵条纹压成了
   深灰叠深灰、榆蓝叶甲的金属蓝绿压成了近黑、红萤的鲜红警戒色压成了闷暗酱红。
   招牌图案在画面上直接消失，而断言只看基色 HSL，一路全绿。
   **要黑白对比，浅色就得真的接近白、深色真的接近黑**；拿不准时对齐
   `ladybird.ts` 的 `#e2382a` —— 那是目视验收过的「够亮」基准。

   **占位几何被当成了成品。** 白蚁兵蚁的头是一个没倒角的 `BoxGeometry`，在一群
   光滑放样的虫子里像个纸箱；大颚是两片扁三角，像剪纸；兰花螳螂的花瓣状腿节是几片
   侧立的窄三角旗，整只虫看着像一只苍白的虾；天蛾的喙是一根三四倍体长的直针，
   像标枪。这些都通过了各自的形态断言 —— 因为断言量的是**数字**（宽厚比、体积占比、
   跨度），而「宽而扁」「够长」这类数字，一块平板和一片花瓣是一样的。
   **派活时要把数字下限和上限一起给**（天蛾的喙就是只给了下限才长成标枪），
   并且始终以「一个人看到这张图会说这是什么虫」作为最终判据。
4. 不像的打回重做，像了才提交、重新部署
5. 更新本文件的完成清单
