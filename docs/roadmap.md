# 物种路线图

目标 **60 种**。每一种的入选标准只有一条：**有一个别的物种没有的招牌结构**，
且这个结构能在程序化建模里做出来、能在 24×24 的剪影里认出来。

数量不是目的。凑不出招牌特征的物种宁可不做 —— 图鉴的价值在于每一页都值得看，
而不在于页数。甲虫尤其要注意：鞘翅目物种数最多，但大量差异在刻点、绒毛、
斑纹这类**细部**上，当前精度表达不出来，做出来就是「又一只褐色的甲虫」。

## 每轮的作业顺序

1. 从上表取 8 种，派 3 个建模 agent + 1 数据 + 1 讲解 + 1 剪影
2. 跑全量测试与 `tsc`
3. **在 `/preview.html` 里逐个放大目视验收** —— 这一步不能省，也不能抽查。
   测试全绿不等于长得像：萤火虫曾被做成两只虫黏一起、螳螂趴平成绿枝、
   帝王蝶糊成一片褐色，当时测试全是绿的。
4. 不像的打回重做，像了才提交、重新部署
5. 更新本文件的完成清单
