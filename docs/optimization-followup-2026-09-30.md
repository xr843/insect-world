# 审核后续实施（2026-09-30）

承接首批审核与上线，落实反馈边界、模块预取和首个物种的来源核校。

## 已实施

- 反馈端点按实际 UTF-8 流字节计量，上限 8 KiB；超限取消读取并返回413。不依赖客户端声明的 Content-Length；正确处理跨块中文。合法 JSON 的 null、数组、标量统一拒绝400，正常500字中文仍可提交。
- 提交等待15秒后中止请求并允许重试，保留正文和邮箱。HTTP200必须同时带有效 JSON `{ok:true}` 才算收件；HTML回落页或错误收件确认不会清空草稿。超时不能证明服务端没有写入，当前没有幂等键；重试可能重复，仍受每日额度约束。
- 成虫和生活史预取只下载、求值模块，实际展示才构建几何；共用导入任务，失败后可以重试。首屏实际展示的成虫仍提前启动构建，与WebGL初始化并行，保留原有加载路径。
- 独角仙中英文详情接入三条来源及具体支持范围，修正未经核实的拖拽倍数、体长测量口径、固定阶段时长和白天藏身位置；同步相关课程段落。核校仅覆盖列举断言，其他62种仍待逐条核校，未做专家复审。详见[核校矩阵](content-audit-rhinoceros-beetle.md)。

## 缓存实测及边界

真实Chromium遍历18种的48个生活史模型：3,937个独立几何、412个材质，几何TypedArray缓冲共36,479,990字节（34.79 MiB）。请求GC后堆增量68.83 MiB，包含模块/运行时，不能当作纯模型或显存占用。阶段模型并非都很小。

改动后预取全部63成虫与48阶段模块，两模型缓存均为0；CDP查询并请求GC后，BufferGeometry/Material/Texture实例数量与预取前相同。另有20物种预取压力测试，验证当前ant模型未被逐出、没有dispose事件。

这只消除了预取导致的构建。实际展示过的阶段仍会积累；成虫12项LRU仍没有活跃引用保护。隔离测量中持有ant后加载12个其他成虫会将其逐出；同一模型共享资源还会重复dispose。后续必须先加入展示/对比/0.24秒离场消费者的引用保护，再实现有上限的阶段缓存和资源去重释放，避免对仍在渲染的对象调用dispose。

原始测量脚本与JSON保存在忽略目录 `audit-out/2026-09-30/`：`stage-cache-measure.*`、`module-prefetch-measure.*`。上述数值只针对本次构建和遍历顺序。

## 首屏基线

对改动前456aedc构建，以`perf-firstframe.mjs`、全新浏览器上下文、冷缓存各测3轮：中文桌面首帧971.6/1049.1/1084.3ms（中位1049.1）；英文移动视口、4G、CPU×4为4916.4/4659.7/4844.4ms（中位4844.4）。软件渲染SwiftShader，不能代表真实手机GPU。入口JS传输约297KiB、英文语言包约111KiB；语言包、主线程几何构建和首次绘制均需继续评估。

本轮不宣称首屏提速；没有改变渲染器分包架构。下一步可评估延迟加载Canvas，但须同时保留实际首屏模型预热，并对照测试加载提示、WebGL兜底和真实设备首帧。
