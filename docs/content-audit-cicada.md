# 黑蚱蝉第五批局部内容核校

核对日期：2026-10-17，物种 `cicada` / *Cryptotympana atrata*。核对发声装置与鸣声强度、生活史（卵越冬、若虫期年限与龄数、出土羽化）、口器与取食、产卵致枝条枯死与害虫地位、分布，以及与北美周期蝉的对比等叙述。本轮不代表整物种所有字段核验完成，也未做昆虫学专家复审。

## 改动与边界

- 总述：删除“夏季最常见”和“地面上的寿命只有数周”，改为声学学报前言的“分布广泛的常见大型蝉类”；羽化地点按综述写作“附近树木或杂草”。
- 体长：原“44–48毫米、翼展约120毫米”没有来源，翼展删除。体长改为北京7只实测样本的平均值约39.9毫米（原文39.9±1.6毫米；不把均值±标准差写成体长范围），并在数值里标注口径。这是北京一地的小样本均值，不代表全分布区个体的变幅。
- 生活史：本轮所有来源都没有本物种成虫个体寿命，删除“成虫仅存活数周”及课程第4条标题“地下多年只为几周”。改为“通常3–5年或更久”（综述）和“羽化约20天后开始交配产卵”；生活周期改为“卵（在枝条中越冬）→若虫→成虫”；课程补充5个龄期（昆虫学报摘要）。
- 鸣声：删除“近距离90分贝以上”“每秒收缩数百次”“昆虫界数一数二”。改为2米处约79–82分贝、脉冲重复频率约180赫兹、两侧鼓膜交替振动。伊利诺伊页面的90分贝是北美蝉类的一般说法，不用于本物种。
- 腹部：“近乎中空如共鸣箱、成倍放大”改为“近似扁卵形的气室起共鸣腔作用，改善音色、提高输出功率”。删除“雌虫腹部相对实心、不会鸣叫”：本轮只有北美页面对蝉类的一般说法，不直接推到黑蚱蝉。
- 口器与食性：删除“木质部导管”，因为只有ZooKeys引言对蝉类的一般转引。改为刺吸式口器、喙管内含口针、成虫刺吸树木汁液、若虫吸食根部汁液。删除“常被误解为啃树叶”的论断，以及测验解析中“不捕食其他昆虫”的绝对说法；解析改为正面陈述资料记载的食物，正确答案仍为下标1。
- 热点：翅删去“翅脉清晰、停栖时呈屋脊状”；复眼删去“合力感知光线变化”；头部删去“容纳肌肉群”；均改为综述中的形态描述。热点条数与anchor不变。
- 动态卡：删除傍晚出土、背部沿中线裂开、乳白色成虫、持续一两个小时、几乎无法防御等说法。这些说法要么无来源，要么只见于北美周期蝉。改为出土后爬树、在枝叶或树皮上蜕皮、留下蝉蜕，以及金衢盆地的出土时间。本轮不涉及模型动画。
- 冷知识与第二道测验：删除“若虫地下年限不同步”这一机制解释，没有用删掉绝对词来证明相反。改为事实对比：北美周期蝉每13或17年集中出土；本物种每年七八月有成虫产卵，金华报告记载以枝条中的卵和土中各龄若虫越冬。题干和选项随之改写，正确答案仍为下标1。
- 生态与地位：删除“一定程度影响树木长势”“鸟类与土壤生物的资源”以及“偶”“轻度”。改为产卵致枝条枯死、被视为林木和果园害虫、局部曾暴发成灾，并补充来源支持的蝉花寄生、蝉蜕入药和若虫食用。
- 分布：删除“中国大部分地区”和“日本”（综述指出西北和草原区很少）。改为中国东部和中部分布广泛，另记载于朝鲜半岛、东南亚北部等地。
- 栖息：成虫白天活动及9点至17点的高峰来自金华机场观察，正文已限定地点。
- 仍未核校：relatives（螗蝉没有来源；蟪蛄、蒙古寒蝉只是ZooKeys中同地的优势种，并同属蝉亚科，不能证明亲缘最近）、epithet。来源区每条只列支持范围与获取方式，不添加整物种“已验证”标记。
