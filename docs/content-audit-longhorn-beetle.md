# 星天牛第五批局部内容核校

核对日期：2026-10-17，物种 `longhorn-beetle` / *Anoplophora chinensis*。核对成虫形态与体长、生活史与幼虫蛀食、寄主与危害、分布与传播途径相关叙述，不代表整物种所有字段核验完成，未做昆虫学专家复审。

## 改动与边界

- 体长由「约20–39毫米」改为「约19–37毫米」；总述、体长、热点和第一课中「触角两倍以上」「近两倍」统一改为雄虫约1.7–2倍、雌虫约1.2倍。删去「大型天牛」这一来源未给定的说法。
- 删去「成虫寿命约1个月」：EPPO数据表未写，EFSA只转引CABI，Haack指出寿命受寄主和温度影响。生活史改为「通常1年，有时2年；多数以幼虫越冬」。EFSA提到温带地区可能更长，本轮未写入固定上限。
- 「柑橘、杨柳等重要蛀干害虫」改为在亚洲是柑橘园重要害虫；杨、柳只是寄主名单中的属，不写成主要危害对象。生态段删去「风折」，改为来源所述输导组织受损、树体变弱并可致死；「许多国家列为检疫性有害生物」收窄为欧盟检疫性有害生物和EPPO A2名单。
- 栖息环境删去「阔叶林」，改为亚洲果园与引入地城市树木；没有采用「从未在天然林发现」，以免与2026年克罗地亚林地诱捕记录冲突。
- 感知事实删去「触角遍布感受器、感知振动寻找寄主」，改为2010年综述所述接触和近距离信息素寻偶，标明年份。
- 热点：删去复眼「肾形、为触角让出空间」、足「跗节黏毛」、前胸侧刺「防御结构」、上颚「粗壮有力」和「斑纹因个体而异」等无来源说法。复眼和足两处来源无描述，只保留位置性描述（头部两侧一对复眼、三对足在树干枝条上爬行），不写形态细节与功能；前胸背板改用EFSA描述的尖突与毛斑变化；鞘翅补入来源明确的基部颗粒状小突起。
- 课程与测验：删去「卵槽用分泌物封住」「刻槽帮初孵幼虫钻入」，改为切口用于插入产卵器、每处产一粒卵；第一题正确选项依赖被删说法，已改题，答案下标仍为1。删去「很难找到相同两只」和「黑白配色易被发现、与拟态策略相反」，后者与来源所述早期难以发现相反。动态卡删去「顺木纹延伸数十厘米」，改为形成层取食道、边材心材隧道、多数向下至根、蛀道末端化蛹。
- 冷知识、第二题与分布：删去「木质包装材料」传播（Haack：活体植物截获99%为星天牛；EFSA：EPPO区域未记录木质包装截获），改为盆景和苗木；删去「近二十年在法国建立野外种群」，法国疫点已于2024年宣布根除；第二题题干由「在欧洲多国建立野外种群」改为主要传入途径，正确选项仍为下标1。分布补入日本，欧洲按2026年分布表写意大利、土耳其局部分布及克罗地亚少量发生，美国疫点已根除；删去「北美多次被截获」。
- 生活史列表保持卵、幼虫、蛹、成虫四项，去掉幼虫期固定年数，改为产卵位置、蛀食部位、越冬阶段和蛹室位置。
- 仍未核校：近缘种列表（桑天牛、云斑天牛不在来源中）、中文名与光肩星天牛等中文译名、别称文案、3D模型与动画表现。来源区每条只列支持范围与获取方式，不添加整物种「已验证」标记。
