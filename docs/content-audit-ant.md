# 日本弓背蚁第五批局部内容核校

核对日期：2026-10-17，物种 `ant` / *Camponotus japonicus*。核对范围：工蚁大小分化与分工、触角识别同巢伙伴、工蚁体长与巢址分布、蚁后封闭建巢与首批工蚁。这不代表整物种所有字段已核验完成，也未做昆虫学专家复审。

## 改动与边界

- **总述**：删除“信息素协调分工”“地下或朽木中的分室巢穴”“蚁后深居中心、终生专事产卵”。改为大小工蚁及其分工（Ma等）、触角感受体表碳氢化合物识别同巢伙伴（Watanabe等），以及开阔地土中营巢、巢口直接开在地面（数据库）。“东亚常见的大型蚂蚁”改为来源原意“东亚分布广泛、体型较大”。
- **体长**：由“7–13毫米、蚁后约17毫米”改为数据库的“工蚁约7–12毫米”，保留“数字–数字毫米”格式；蚁后体长无来源，删去。
- **负重、寿命、食性**：删去“数十倍体重”“蚁后十余年、工蚁两年内”“杂食、捕虫、吸汁、放牧蚜虫”。本轮来源均未涉及这些内容，事实卡改为“暂无可核实的本物种……数据”，不给相反结论。
- **栖息环境、分布**：删去石块下、朽木和分室巢穴，改为数据库原文范围。分布删去“东亚周边地区”，只列日本、中国大陆、朝鲜半岛。
- **协作事实与第四课**：删去“触角敲击交流分工”“集体效率远超个体”“视力有限、靠气味痕迹归巢”，改为本种用18种体表碳氢化合物、按各巢配比识别同伴，并对外巢个体表现攻击。
- **热点**：
  - 上颚：改为大小工蚁头宽与上颚长度差异及大工蚁守巢，不再说切割食物。
  - 后腹部：删除嗉囊与蜜露，改为数据库记载的第2节背板软毛列数。
  - 触角：删去“膝状”“传递信息素”，改为每根触角约180个锥形感器。
  - 复眼：删去视力有限的说法，改为头部颜色及中国北方高纬度种群栗红色头部更常见。
  - 腹柄节、足：只删去功能与能力描述（灵活摆动、黏垫、攀爬光滑垂直面），保留部位说明。这两处保留内容并非来自来源，列入未核实项。
- **第一课与第一道测验**：删去细腰用于蜇刺、喷酸及“区别于多数其他昆虫”的说法。课程改为只指出腹柄节位置，并说明其功能暂无可靠资料。原题的正确答案依赖被删说法，因此整题改为考查同巢识别，答案下标仍为1。删去蜇刺和喷酸不等于证明本种没有这些行为。
- **第二课**：改为来源支持的大小工蚁上颚差异与分工，删去“粗壮如钳”和搬运沙土。
- **第三课**：原蜜露、嗉囊、口对口分享无来源，改为后腹部软毛的形态描述，锚点不变。
- **动态卡**：放牧蚜虫、驱赶天敌、搬运蚜虫群均无来源，改为遇到外巢蚂蚁时的攻击反应，挥发物实验按“初步实验”表述。卡片注明模型动作只是示意。本轮未新增动画。
- **冷知识与第二道测验**：删去蚁后脱翅后终生不离巢、寿命十余年、“最长寿昆虫类群之一”。冷知识改为日本婚飞季节，以及封闭建巢时首批工蚁数量与个头的权衡。寿命题整题改为考查该权衡，答案下标仍为0。
- **生态**：删去土壤翻动、养分循环、与蚜虫互利、鸟类食物来源。改为本种攻击外巢个体、相邻巢觅食范围分开，蚂蚁整体的生态角色明确以类群口吻表述，并注明本种缺少具体资料。
- **生活史**：删去“蛹（多结茧）”中的结茧说法。成虫分蚁后、雄蚁、工蚁有Ma等支持；卵、幼虫、蛹三个阶段与结构字段一致，但未由本轮来源核实。
- **别称（epithet）**：“终身搬运工”与大工蚁很少觅食的记载不符，改为“土中筑巢、大小工蚁分工”。
- **仍未核校的字段**：近缘物种列表、英文俗名，以及“常见”在日本以外的适用性。来源区每条只列支持范围与获取方式，不添加整物种“已验证”标记。

- 2026-10-17 追加：facts「饲养（实验室蔗糖溶液）」改为「食性：会照料蚜虫，取食蚜虫排出的富含糖分的蜜露」，依据为上述摘要与表2把本种归入照料蚜虫、取食蜜露的蚂蚁，挂 claim `ant-aphid-tending`；「富含糖分」取自引言对蜜露的一般描述。ecology 补一句：先以「有些蚂蚁」概述照料蚜虫、取食蜜露并帮蚜虫抵御天敌（引言综述，限定为部分蚂蚁），再说研究者把本种列为取食蜜露的蚂蚁之一，避免把综述内容说成本种已被观察到的保护行为。facts「气候（21.52°C／−0.65°C）」改为「体色：工蚁通常为黑色，但在中国北方较冷的高纬度地区，头部带栗红色的工蚁更常见」。这一说法沿用课程第3步已挂来源的内容，没有引入新事实；icon 仍为 place，中英 icon 序列不变。原气温数据所依的中国大陆采样来源继续支持 habitat 段的纬度范围与采样点数。表2的乳杆菌检出率（70只中30只）与本种生态关系不直接，未写入正文。
- 与任务说明的出入：任务描述称该文「方法写明采集的是正在照料蚜虫的工蚁，陕西7个地点70只」。核对已抓取的原文后，「7个地点」在文中任何位置都没有出现。「陕西」和「照料蚜虫的工蚁」只见于我们自己写的来源头 NOTES 和表格注释，不是论文原文；方法节选的采集记录也不含本种。因此正文没有写本种的采集地、地点数，也没有写「采集时正在照料蚜虫」。若要使用这些细节，需另取论文全文的方法部分或补充材料核实。
